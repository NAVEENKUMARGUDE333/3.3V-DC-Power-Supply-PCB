# 🔌 3.3V DC Power Supply PCB

## 📌 Project Overview

This project is a **3.3V DC power supply PCB** designed using **EasyEDA**. It uses an LM1117-3.3 voltage regulator to convert a suitable DC input voltage into a regulated 3.3V DC output for low-voltage electronic circuits.

This is **Day 2 of my 30-Day PCB Design Challenge**, where I am improving my PCB design skills through practical electronics projects.

## ⚙️ Features

- DC input supply through a barrel jack
- Regulated 3.3V DC output
- LM1117-3.3 voltage regulator
- Input and output filtering capacitors
- LED power indicator
- Compact PCB layout
- 2D PCB layout and 3D visualization

## 🛠️ Components Used

- LM1117-3.3 Voltage Regulator
- DC Barrel Jack (5.5 × 2.0mm)
- 100µF Input Capacitor
- 10µF Output Capacitor
- Green LED Indicator
- 460Ω Resistor
- 2-Pin Output Screw Terminal

## 💻 Software Used

- **EasyEDA** – Schematic design, PCB layout, routing, and 3D visualization.

## 🔄 Working Principle

1. A suitable DC supply is connected through the input barrel jack.
2. The input capacitor helps reduce input voltage fluctuations.
3. The LM1117-3.3 regulator converts the input voltage to a nominal 3.3V output.
4. The output capacitor helps stabilize the regulated supply.
5. An LED acts as a visual power indicator, with a resistor to limit its current.
6. The regulated 3.3V output is available through the output connector.
